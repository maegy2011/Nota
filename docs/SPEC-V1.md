# Nota V1 — المواصفة النهائية (متفق عليها 20 سبتمبر 2026)

> عربي، مهتم بالخصوصية — اندرويد فقط — offline أولاً — مجاني الأساسي — مدفوع للـ sync — مفتوح المصدر بعد الاستقرار
> منهجية: skill الـ Android

## 1. الرؤية
- ملاحظات عربية سريعة، offline-first، مشفرة محلياً، zero-knowledge
- بديل خفيف لملاحظات جوجل/شاومي — لا إعلانات، لا تتبع، لا قراءة من الشركة

## 2. النطاق V1 (مجاني — offline)
- ملاحظات نصية فقط (عنوان + نص) — بدون صور/مرفقات
- تنظيم: بحث فقط — بدون مجلدات/تاجات
- بحث محلي فوري عربي
- قفل: بيومتريك + PIN + قفل تلقائي (30 ثانية default)
- تشفير محلي: Room + SQLCipher — المفتاح في Android Keystore
- نسخ احتياطي: ملف مشفر بكلمة سر (XChaCha20) + استعادة
- سلة محذوفات 30 يوم + حذف نهائي
- عربي RTL + Tajawal + وضع ليلي + Material You
- حجم < 30MB — cold start < 1s — minSdk 26 — targetSdk 35

## 3. خارج النطاق V1 (مؤجل لـ V2 مدفوع)
- حساب + مزامنة E2EE + أجهزة متعددة
- مرفقات مشفرة + مشاركة مشفرة + إصدارات الملاحظات
- تذكيرات/تثبيت/ودجت (تُدرس بعد V1 حسب الطلب)

## 4. التقنيات V1
- Kotlin + Jetpack Compose (BOM) + Material3
- Room + SQLCipher + DataStore + BiometricPrompt + Hilt
- R8 من أول release — versionCode متزايد — mapping.txt محفوظ
- لا أسرار في APK — لا tracking SDKs — allowBackup=false + dataExtractionRules

## 5. البيزنس
- V1 مجاني للأبد
- V2 Plus: sync + مساحة + مرفقات + إصدارات — Play Billing
- المبادئ: لا إعلانات، لا بيع بيانات، شفافية + open-source clients بعد الاستقرار

## 6. المراحل
- 0: مواصفة (تمت) ← نحن هنا
- 1: هيكل مشروع + شاشات (قائمة/محرر/بحث/قفل/نسخ احتياطي)
- 2: تشفير + قفل + نسخ احتياطي + اختبارات
- 3: إطلاق internal ثم production + audit

## 7. معايير القبول V1
- يعمل بدون نت 100% — بحث عربي فوري — قفل تلقائي شغال
- نسخة احتياطية مشفرة تُستعاد على جهاز آخر بكلمة السر
- لا traffic شبكة إطلاقاً في V1 (تُفحص بـ requests)
- tsc/kotlinc نظيف + release R8 شغال على جهاز حقيقي
